# Quaternius items

- **Author:** Quaternius (https://quaternius.com)
- **Source:** Poly Pizza, which hosts the author's models: `necklace.glb` is "Necklace"
  (https://poly.pizza/m/Jvhs8DCNDZ), `coin_pouch.glb` is "Coin Pouch"
  (https://poly.pizza/m/pTZyPTMH88), `spikes.glb` is "Spikes" (https://poly.pizza/m/wGAKoYCOVK)
  and `pebble.glb` is "Rock" (https://poly.pizza/m/KvXSMwoftt; inside the file its mesh is named
  `Prop_CannonBall`, from the author's pirate kit, and its texture is that kit's atlas), each the
  site's `.glb` download, renamed
- **License:** CC0 1.0, see `LICENSE.md` next to this file (the site names the license; the file is
  its legal text). Credit is welcome, not required. On 2026-10-31 all four pages above still showed
  "Public Domain (CC0)", linked to the CC0 1.0 deed, with the author named and no credit asked
  (#1954).
- **Why that record matters:** the author's own site offers its files under its own asset license
  since 2026-08-28, which forbids redistributing them as assets. These four were taken from Poly
  Pizza under CC0, a dedication that can't be withdrawn, so CC0 governs them. A new download from
  the author's site is refused by `tools/godot/credits.gd` unless the owner allows it (#1954).
- **Used for:** the gear's models (#1581), shown in its gear slot: the necklace for Vis'omera, the
  pouch for the berry pouch and the spikes for the thorn spikes, and the stone material's model
  (#1546), a round pebble a hand holds (item models look held, #1596), until the game's own look
  exists.
- **Only what the game uses is here:** the four models, unchanged, and the texture Godot's import
  extracts from the pebble.
